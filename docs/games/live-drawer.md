# Live Drawer

Colored numbered token pool with multi-draw reveal on the spectator screen.

## Flow

1. **Hostess** enters tokens as guests receive them (number + color, or bulk range like 1–100 for one color). Tap **Birthday** or **VIP** before Add to save a cake or star with those numbers. Tap the same button again to leave the next numbers unmarked. Optional notes stay with the token for hostess and operator only.
2. **Operator** sees pool counts by color, filters the list, and draws. A warning shows when the spectator screen is on another game.
   - **Random by color counts** — e.g. 5 blue + 5 red from the pool without replacement. **Any** draws that many tokens from the whole pool, whatever color is left.
   - **Specific tokens** — pick from the filtered list, then **Draw selected** (also available in Token Summary so you do not need to scroll up).
   - **Queued Tokens** — select pool tokens and **Queue tokens** in Token Summary to prepare a set that will be called together. Groups stay on one row (scroll sideways if needed) and use two columns only when there is room. Use **Add** on a group to add more numbers. Tap a number once to mark it red, then tap again to remove it. Press **Draw** on the group you want to call, or × to remove the group. The queue survives refresh.
3. **Spectator** animates the reveal: one large tile or a grid for multiple tokens.
4. **Clear** hides the spectator display without returning tokens to the pool.
5. **Draw history** lists each draw in a compact row, newest first. Hover a number and choose **Return** to put that one number back in the pool if it was a mistake. The rest of the draw stays called. **Clear history** removes the history list without deleting called numbers.

## Countdown

Optional, in the right column above **Draw history**. Use **Show** / **Hide** beside the clock. Pick **30s**, **45s**, or **1m**, or set a custom length, then **Start** at the bottom. The big screen shows only the time. **Reset** hides it until the next start. Turning the countdown off hides it immediately. Collapse the right column with the panel button when you want more room for Token Summary.

## Colors

Red, blue, green, yellow, orange, purple, pink, black, white — same presets as physical token colors. Black tokens use a black circle with white numbers; white tokens use a white circle with black numbers.

## Operator corrections

The operator can add or remove tokens from the pool (e.g. fix hostess entry errors). Use **Add tokens** in Token Summary to open the form. To delete numbers, select them and press **Delete selected**. Hover the info icon for how to enter one number, a comma list, or a range. Optional notes can be added when creating a token or edited later with the note icon under each token. A **Notes** list beside Token Summary shows every pool or called token that has a note. Click a row or the note icon to open the note form — save a new note or choose **Clear note**. **Clear pool** on the pool summary deletes every remaining pool token. That action asks for confirmation and does not touch called numbers or the spectator display.

On the **Called** tab, tap numbers to select them, then **Return selected** to put those back in the pool.

## Birthday and VIP marks

The hostess can set a cake (birthday) or star (VIP) while adding a token. In the operator **Add tokens** form, **Birthday** and **VIP** sit under the color buttons. Turn one on before **Add to pool** to save that mark with the numbers. Tap the same button again to add unmarked numbers. Under each token, the operator can also click the mark until it shows a cake, a star, or a plain circle (no mark). Filter the pool or called list to Birthday, VIP, or **None** (unmarked), select that token, and use **Draw selected** when that guest should play. The spectator screen never shows the mark or the note.

The number pool, colors, birthday or VIP marks, and notes stay in the pool. There is no separate save list. Called numbers stay called.
