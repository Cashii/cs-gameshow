# Live Drawer

Colored numbered token pool with multi-draw reveal on the spectator screen.

## Flow

1. **Hostess** enters tokens as guests receive them (number + color, or bulk range like 1–100 for one color). Tap **Birthday** or **VIP** before Add to save a cake or star with those numbers. Tap the same button again to leave the next numbers unmarked.
2. **Operator** sees pool counts by color, filters the list, and draws:
   - **Random by color counts** — e.g. 5 blue + 5 red from the pool without replacement
   - **Specific tokens** — pick from the filtered list
3. **Spectator** animates the reveal: one large tile or a grid for multiple tokens.
4. **Clear** hides the spectator display without returning tokens to the pool.
5. **Draw history** lists each draw in a compact row, newest first. Hover a number and choose **Return** to put that one number back in the pool if it was a mistake. The rest of the draw stays called.

## Countdown

Optional, and its own section under **Draw controls**. Turn it on, pick a length, then **Start**. The big screen shows only the time. **Reset** hides it until the next start. Turning the countdown off hides it immediately.

## Colors

Red, blue, green, yellow, orange, purple, black, white — same presets as physical token colors. Black tokens use a black circle with white numbers; white tokens use a white circle with black numbers.

## Operator corrections

The operator can add or remove tokens from the pool (e.g. fix hostess entry errors), or **Clear pool** from the pool summary to delete every remaining pool token. That action asks for confirmation and does not touch called numbers or the spectator display.

## Birthday and VIP marks

The hostess can set a cake (birthday) or star (VIP) while adding a token. Under each token, the operator can click the mark until it shows a cake, a star, or a plain circle (no mark). Filter the pool or called list to Birthday or VIP, select that token, and use **Draw selected** when that guest should play. The spectator screen never shows the mark.

The number pool, colors, and birthday or VIP marks stay in the pool. There is no separate save list. Called numbers stay called.
