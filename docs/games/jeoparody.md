# Jeoparody

Jeopardy-style category board. Buzzers stay in the room; the operator is the only on-screen control.

No Daily Double or Final Jeopardy.

## Operator

- **Setup:** edit contestant names and scores; add or remove categories and clues (value, prompt, response)
- **Play:** click a cell to put the prompt on the spectator screen
- Reveal or hide the response
- Award **correct** (+value) or **incorrect** (−value) to a contestant
- Return to the board (that cell stays empty)
- Reset board and reset scores separately
- Toggle contestant scores on the spectator screen

## Spectator

Shows the category grid with unused dollar values. Played cells are blank. While a clue is open, the display shows the prompt, then the response when the operator reveals it. Contestant scores sit along the bottom when enabled.
