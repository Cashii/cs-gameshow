# Price Wheel

A spectator scoreboard. The operator adds as many players as they want. Each player is a name and a score.

## Operator

- **Add player**, then type the name and score.
- Remove a player with the trash button.
- Set Spectator screen to **Price Wheel** to put the board on the projector.
- A warning shows when the spectator screen is on another game.

## Spectator

Names and scores fill the screen. They grow as large as the number of players allows. Nothing else is shown.

Player names and scores stay on the player list. There is no separate save list.
