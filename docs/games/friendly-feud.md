# Friendly Feud

Survey-style board game with team scores, strikes, and answer reveals.

## Operator controls

- Pick a question, reveal answers, add strikes
- Adjust team names and scores
- Toggle header, team scores, and answer point values on spectator
- A warning shows when the spectator screen is on another game

## Spectator

Shows the question, answer board (hidden/revealed), strike count, and team scores.

## Questions

Click the question above the board to open every question. Each one shows its answers and points. Pick a question to show it. From that list, add a question, change its wording, or delete it. The buttons beside the question still add or edit the one on the board.
