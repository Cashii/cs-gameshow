# Message Board

Utility screen for announcements. The operator types a message or shows a saved one; the spectator display shows it.

## Operator

- Type what the projector shows. It updates as you type, in a short box at the top.
- Change the message size for the projector
- Groups sit in a list on the left titled **Groups**, starting with **All**. The folder icon with a plus adds a group. Type the group name in the box that opens. Double-click a group name to rename it, or delete it from the trash icon. Deleting a group leaves its messages ungrouped.
- Saved messages for the selected group sit to the right. The message icon with a plus on that list adds a quick message. It opens a box where you type the message. New messages go into the group you have selected.
- Click a saved message to put it on the screen. The pencil opens a list so you can choose its group, and the trash deletes it. Those buttons do not put the message on the screen.
- Save the message that’s on screen, or clear it
- Set Spectator screen to **Message Board** to put it on the projector

## Spectator

Shows the Jack'd Up logo at the top and the current message centered on a branded background. Empty if nothing is set. Groups stay on the operator desk.
