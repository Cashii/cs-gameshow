# Jack'd Up design

Brand look for the spectator screens, standby logo, and operator marks. Use these colors instead of inventing new ones.

## Colors

| Token | Hex | Use |
| --- | --- | --- |
| Ink black | `#0a0a0a` | Stage background. The Jack'd Up logo is meant to sit on this. |
| Deep black | `#050505` | Top of a vertical stage gradient. |
| Night purple | `#0d0714` | Bottom of a vertical stage glow, very subtle. |
| Green | `#3dff8a` | Jack'd lettering, left / first-choice accents, live highlights. |
| Green deep | `#0f9f55` | Shadows and darker green fills behind green type. |
| Purple | `#c084fc` | UP lettering, right / second-choice accents. |
| Purple deep | `#7c3aed` | Shadows, curtain folds, deeper purple fills. |
| Gold | `#ffdc14` | Diamond frame, winners, timers, underlines, trim. |
| Gold soft | `#fff794` | Soft gold glow, sparkles, secondary gold type. |
| Cream | `#f7f3ea` | Main audience type on dark stages. |
| Cream muted | `rgba(247, 243, 234, 0.58)` | Labels, empty states, helper type. |

Do not use theater red, sky blue, or teal as the main spectator palette. Teal is for operator controls only (active nav, primary buttons).

## Stage

Dark Jack'd Up boards use a stacked background:

1. Soft green radial glow in the center.
2. Soft purple radial in a lower corner.
3. Soft gold radial in the opposite lower corner.
4. Vertical gradient from `#050505` through `#0a0a0a` to `#0d0714`.

Optional sparkles: tiny cream, gold, green, and purple dots. Keep them quiet.

## Type

- **Gameshow body** — Oswald (Impact / Arial Black fallback). Titles, clocks, answers, hints.
- **Jack'd script** — Pacifico. Only for the word "Jack'd" in the operator sidebar mark.
- **UP** — Oswald, uppercase, purple. Pair with script Jack'd. Do not put both words in Pacifico.

Audience type is cream on dark, with a light green or gold glow on big words. Do not use black type on the spectator stage.

## Pairings

- **Green + purple** — two-sided choices (true/false, two teams, two answers).
- **Gold** — the surviving / winning / timed thing. One gold emphasis at a time.
- **Green + gold** — Jack'd wordmark energy without crowding purple.
- **Purple + gold** — UP, curtains, decorative frames.

## Operator vs spectator

| Surface | Palette |
| --- | --- |
| Spectator / big screen | Ink black, green, purple, gold, cream |
| Operator desk | Neutral gray chrome, teal for the control you are on, green/purple only in the Jack'd UP mark |
| Player phones | Match spectator when the game is on screen; standby uses the full Jack'd Up logo |
